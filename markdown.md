# Class Notes

This file is Markdown. Markdown is just plain text with a few punctuation conventions that turn into formatting. You can read it in its native format to see the raw characters, or preview it to see the 'rendered' version.

Markdown is worth learning because it is used *everywhere*: GitHub, Slack, Discord, Notion, Linear, Obsidian, every README, much of what you'll write to/from/with engineers, AND it's the lingua franca of LLMs. AI agents use markdown. And it's nice to read and write!
