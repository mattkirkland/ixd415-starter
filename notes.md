# Class Notes

This file is Markdown. It's plain text with a few punctuation
conventions that turn into formatting. You are reading the rendered
version right now — open it in VS Code to see the raw characters, and
press `Cmd+Shift+V` (Mac) or `Ctrl+Shift+V` (Windows) to toggle back.

Markdown is worth twenty minutes of your life because it is
*everywhere*: GitHub, Slack, Discord, Notion, Linear, Obsidian, every
README on earth, and most of what you'll write alongside engineers.
